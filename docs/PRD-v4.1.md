# tg-bridge v4.1 控制面板

状态 CONFIRMED
版本 v4.1
前版路径 `docs/PRD-v4.md`（CONFIRMED 2026-11-10，保留不改）
依据 2026-11-10 使用者在手机上用 v4 的 `/config`，希望它像 Telegram 里常见的配置菜单：先看状态，按钮进下一级，能返回，能收起
确认依据 2026-11-10 对话中使用者描述的三点：输入后先给状态列表；按钮进入默认端点页，显示当前默认端点、API key、端点名称和切换；点完能返回
定稿日期 2026-11-10

## 结论

`/config` 改为一条可以原地翻页的控制面板。所有翻页、切换、返回、收起都编辑同一条消息，不在群里新增消息。v4 的其他行为不变。

## 页面

| 页面 | 内容 | 按钮 |
|---|---|---|
| 首页 | bridge 在线状态（Telegram、Herdr）；默认端点；全部端点名；开着的话题数，按端点分开；运行中会话数；额度 | 默认端点、全部端点、刷新、收起 |
| 默认端点 | 端点名称、类型、启动方式、网关、API key、话题数 | 每个其他端点一个「切换为」按钮；返回首页 |
| 全部端点 | 每个端点一行：是否默认、类型、网关 | 每个端点一个按钮进详情；返回首页 |
| 端点详情 | 同默认端点页的六项 | 不是默认时有「设为默认」；返回全部端点 |
| 收起 | 一行：面板已收起和当前默认端点 | 展开（回首页） |

切换后留在原页面，页首显示「已切换为 X」。

## API key

- 只对自定义端点显示，来源是新增的可选配置 `TG_BACKEND_<名>_KEY_FILE`（启动命令读的那个 key 文件）。
- 只显示末 4 位和总长度，形如 `••••a1b2（共 40 位）`，每次翻页时现读文件，换 key 后马上能看出来。
- 没配、读不到、文件为空分别写明。内置的 `claude`、`codex` 显示「不用 key，用登录状态」。

## 兼容

- `/config default codex` 文字命令保留。
- v4 发出的旧 `/config` 消息上的按钮（`cf:default:<名>`）点了仍然生效，点完那条消息变成默认端点页。
